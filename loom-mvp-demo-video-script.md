# LOOM MVP — Demo Video Script

**Target length:** 2–3 minutes
**Goal:** Show what LOOM does, why it matters, and how the MVP proves the core idea works.
**Live link:** https://gundlururajasekhar.github.io/Multi-agent-loom-app/

---

## Recording setup checklist
- [ ] Close unrelated tabs/apps — keep the browser and any terminal you'll show
- [ ] Zoom browser to ~110–125% so text is readable on a recorded video
- [ ] Use a screen recorder (OBS, Loom.com, or built-in OS recorder) at 1080p, 30fps
- [ ] Do a 10-second mic test before the real take
- [ ] Have the LOOM MVP link already loaded in a tab, refreshed clean
- [ ] Silence notifications

---

## Scene 1 — Hook (0:00–0:15)
**On screen:** Your face (optional) or the LOOM landing page loading
**Say:**
> "Building software today usually means one person — or one AI — trying to do everything: research, code, test, ship. LOOM flips that. It's a multi-agent orchestration engine where specialized AI agents handle different parts of the work, together. This is the MVP."

---

## Scene 2 — The problem, fast (0:15–0:30)
**On screen:** Stay on landing page or a simple slide/diagram
**Say:**
> "Most AI coding tools are single-agent — one model doing everything sequentially. That's slow and error-prone for real projects. LOOM's core idea: split the work across agents that specialize — R&D, code synthesis, workflow orchestration, and creative execution — and coordinate them."

---

## Scene 3 — Live walkthrough of the MVP (0:30–1:45)
**On screen:** Navigate the actual deployed app at the link above
**Say (adapt to what's actually on screen):**
> "Here's the MVP running live on GitHub Pages. [Point to landing/index page] This is the entry point — it lays out what LOOM does and how the agents fit together."
>
> [Click into any interactive element / demo flow]
> "Let's walk through a core flow — [describe whatever action the MVP supports, e.g., 'submitting a task and watching it route to an agent']."
>
> [If applicable] "You can see the requirements and task breakdown are documented alongside the app — that's intentional. Requirements, tasks, and the readme all live in the repo so the plan and the code stay in sync."

**Tip while recording:** Narrate what you're clicking *before* you click it, so the video and voice stay in sync during editing.

---

## Scene 4 — Why this matters / what's next (1:45–2:15)
**On screen:** Back to landing page or a simple closing shot
**Say:**
> "This MVP is deliberately narrow — it proves the one core problem: can agents actually coordinate on a task end-to-end? The next steps are [pick 1–2 real next steps, e.g., 'adding persistent agent memory' or 'wiring in a second agent type']."

---

## Scene 5 — Close (2:15–2:30)
**Say:**
> "That's LOOM's MVP. Link's in the description if you want to try it yourself — feedback's welcome."

---

## After recording
- Trim dead air at the start/end
- Add captions if posting publicly (accessibility + muted autoplay views)
- Export at 1080p; keep a copy of the raw take before trimming
